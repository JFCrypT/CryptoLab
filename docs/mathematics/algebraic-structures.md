# Algebraic structures for cryptography

CryptoLab limits abstract algebra to structures and computations that directly support
cryptographic mathematics. The implementation does not attempt to become a general
computer-algebra system.

## Structural hierarchy

A **semigroup** is a set with an associative binary operation.

A **monoid** is a semigroup with an identity element.

A **group** is a monoid in which every element has an inverse. A group is **abelian** when
its operation is commutative.

A **ring** has an abelian additive group and an associative multiplication that distributes
over addition. CryptoLab uses rings with identity when discussing residue classes.

An **integral domain** is a commutative ring with identity, with `1 != 0`, and without
non-zero zero divisors.

A **field** is a commutative ring with identity, with `1 != 0`, in which every non-zero
element has a multiplicative inverse. Zero is not required to have a multiplicative inverse.

## The residue-class ring Z_n

For every modulus `n >= 2`, `Z_n` is a commutative ring with identity.

- `(Z_n, +)` is a cyclic additive group of order `n`.
- `Z_n^×` is the multiplicative group of units.
- A residue belongs to `Z_n^×` exactly when it is coprime to `n`.
- `Z_n` is an integral domain exactly when `n` is prime.
- `Z_n` is a field exactly when `n` is prime.

Inspect a bounded residue-class ring:

```bash
uv run cryptolab --explain algebra zn 15
```

The explanation lists the units and the non-zero zero divisors. Enumeration is deliberately
bounded by the project resource policy.

## Element order

The order of an element is the smallest positive exponent that returns the identity.

For the additive group, powers mean repeated addition:

```bash
uv run cryptolab --explain algebra order 5 17 --operation additive
```

For the multiplicative group, the input must be a unit:

```bash
uv run cryptolab --explain algebra order 3 17 --operation multiplicative
```

CryptoLab rejects a non-unit in the multiplicative command because group order is defined
there only inside `Z_n^×`.

## Generated subgroups

The subgroup generated by `g` is written `<g>`.

```bash
uv run cryptolab algebra subgroup 6 15 --operation additive
uv run cryptolab algebra subgroup 4 15 --operation multiplicative
```

The output begins with the identity and lists successive powers without repeating the final
identity.

## Generators and primitive roots

A generator has order equal to the order of the ambient group.

```bash
uv run cryptolab algebra generators 12 --operation additive
uv run cryptolab algebra generators 8 --operation multiplicative
```

A multiplicative group need not be cyclic. When it is not cyclic, CryptoLab returns a valid
empty generator set rather than treating the result as an execution error.

A **primitive root modulo a prime** is a generator of `Z_p^×`:

```bash
uv run cryptolab --explain algebra primitive-roots 17
```

The initial implementation restricts primitive-root enumeration to prime moduli, matching
the approved educational scope.

## Resource boundary

Commands that enumerate groups or residue sets accept moduli at most `4096`. This is a
laboratory limit, not a mathematical limit.
