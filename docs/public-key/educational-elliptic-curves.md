# Educational elliptic-curve arithmetic

CryptoLab implements transparent arithmetic on deliberately small short-Weierstrass curves
of the form

\[
y^2 \equiv x^3 + ax + b \pmod p,
\]

where `p` is an odd prime no larger than 257. These parameters are chosen for inspection,
not security.

## Non-singularity

A curve is accepted only when

\[
4a^3 + 27b^2 \not\equiv 0 \pmod p.
\]

A singular equation does not define the elliptic-curve group used by the project and is
rejected.

## Point representation

Finite points use the canonical CLI token `x:y`. The additive identity is represented by the
literal token `infinity`. Coordinates are normalized to `0, ..., p - 1` and every finite
input point is checked against the curve equation.

## Operations

CryptoLab exposes:

- complete point enumeration;
- the point at infinity;
- point negation;
- point addition;
- point doubling;
- scalar multiplication with right-to-left double-and-add;
- point order;
- the cyclic subgroup generated by a point.

Affine addition uses a slope computed with a modular inverse. Vertical lines and a tangent
at a point with `y = 0` produce the point at infinity.

## Example curve

The curve

\[
y^2 = x^3 + 2x + 2 \pmod{17}
\]

has group order 19. The point `5:1` generates the complete group:

```bash
cryptolab --explain public-key ecc inspect 17 2 2
cryptolab --explain public-key ecc add 17 2 2 5:1 5:1
cryptolab --explain public-key ecc multiply 17 2 2 3 5:1
cryptolab --explain public-key ecc subgroup 17 2 2 5:1
```

The first multiples are

```text
1P = 5:1
2P = 6:3
3P = 10:6
19P = infinity
```

## ECDLP relation

Given points `P` and `Q = kP`, the elliptic-curve discrete logarithm problem asks for the
integer `k`. CryptoLab introduces this relation on tiny groups only. It does not implement
elliptic-curve cryptanalysis and does not present these curves as secure.
